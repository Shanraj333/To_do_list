# To-Do List 📝

## 📌 Overview
**To-Do List** is a simple and interactive web application built using **HTML, CSS, and JavaScript** that helps users manage daily tasks efficiently.

The app allows users to add, mark, and delete tasks with a clean and user-friendly interface.

---

## ✨ Features
- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Persistent tasks (using browser storage, if implemented)
- 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack
- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript (ES6)** – Logic & DOM
